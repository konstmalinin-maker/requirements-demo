# Глоссарий

| Термин | Определение |
| --- | --- |
| SRS | Спецификация требований к программному обеспечению |
| BR / UR / FR / NFR | Бизнес-, пользовательское, функциональное и нефункциональное требование |
| RTM | Матрица связей требования с Issue, коммитом, кодом, тестом и результатом |
| REQ-ID | Стабильный идентификатор требования, например FR-001 |
| Версия требования | Редакция одного ID: FR-001@v1, затем FR-001@v2 |
| Заметка | Заголовок, текст, UUID и даты создания/обновления |
| Хранилище | Локальный UTF-8 JSON-файл со списком заметок |
| Атомарность | Читатель получает старую либо новую полную версию файла |
| Верификация | Проверка реализации относительно измеримых критериев |
| Осиротевший тест | Тест с REQ-ID, которого нет в определениях SRS |
| Conventional Commits | Соглашение type(scope): description с ссылкой на REQ |
| Retired | Требование выведено из действия; ID и история сохранены |
