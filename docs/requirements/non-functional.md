# Нефункциональные требования

Каждый ID постоянен и не переиспользуется. Версии имеют вид `FR-001@v1`; изменения проходят через PR.

## NFR-001@v1: Производительность списка
**Приоритет:** Must have.  
**Источник / связь:** BR-002.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Полная команда list, включая чтение 10000 заметок и форматирование результата, выполняется не дольше 500 мс на среде проверки Python 3.12/Linux.

**Критерий приёмки:** Измерение perf_counter в отдельном процессе; размер набора, длительность и среда сохраняются.

**Проверка:** `tests/test_acceptance.py::test_nfr001_list_10000_under_500ms`.

## NFR-002@v1: Атомарность хранения
**Приоритет:** Must have.  
**Источник / связь:** BR-001.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Сохранение выполняется через временный файл в том же каталоге, flush/fsync, os.replace и fsync каталога в POSIX. До replace доступна старая полная версия, после — новая полная версия.

**Критерий приёмки:** Инъекция ошибки до replace сохраняет прежний JSON и удаляет временный файл. Гарантия не охватывает отказ физического носителя и несогласованные параллельные писатели.

**Проверка:** `tests/test_storage.py::test_nfr002_failed_replace_preserves_original`.

## NFR-003@v1: Права доступа
**Приоритет:** Should have.  
**Источник / связь:** BR-001.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

В POSIX файл заметок и временные файлы имеют права 0600: чтение и запись только владельцем.

**Критерий приёмки:** После создания и обновления stat.S_IMODE равен 0o600. На Windows применяются правила ACL и этот POSIX-тест пропускается.

**Проверка:** `tests/test_storage.py::test_nfr003_permissions_0600`.

## NFR-004@v1: Русскоязычные ошибки
**Приоритет:** Must have.  
**Источник / связь:** BR-002.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Все ожидаемые пользовательские ошибки и справка CLI на русском; ошибки содержат понятную причину и подсказку. Ненулевой exit code при ошибке.

**Критерий приёмки:** Проверены валидация, неизвестный ID/команда, битый JSON, запрет доступа и аргументы CLI; traceback не выводится.

**Проверка:** `tests/test_cli.py::test_nfr004_russian_errors`.

## NFR-005@v1: Покрытие тестами
**Приоритет:** Should have.  
**Источник / связь:** BR-003.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Покрытие исполняемых строк src не менее 80%; порог обязателен локально и в CI.

**Критерий приёмки:** pytest-cov формирует XML/JSON/HTML; искусственное добавление непокрытых строк вызывает ненулевой код CI.

**Проверка:** `tests/test_acceptance.py::test_nfr005_public_modules_importable`.

## NFR-006@v1: Локализация
**Приоритет:** Could have.  
**Источник / связь:** BR-003.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Все пользовательские тексты, включая справку, ошибки и подтверждение удаления, хранятся в src/messages_ru.json.

**Критерий приёмки:** CLI и ядро получают сообщения по ключам; JSON читается как UTF-8, проверена полнота словаря.

**Проверка:** `tests/test_acceptance.py::test_nfr006_messages_externalized`.
