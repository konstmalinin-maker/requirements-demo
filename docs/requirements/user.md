# Пользовательские требования

Каждый ID постоянен и не переиспользуется. Версии имеют вид `FR-001@v1`; изменения проходят через PR.

## UR-001@v1: Создание заметки
**Приоритет:** Must have.  
**Источник / связь:** BR-001.  
**Статус:** Реализовано; верификация — по связанным тестам и RTM.

Как владелец локальных заметок, я хочу создать заметку с заголовком и текстом, чтобы сохранить мысль.

**Критерий приёмки:** Созданная заметка доступна после повторного запуска.

**Проверка:** `tests/test_notes.py::test_fr001_ur001_add_persists`.
