- Введены BR-001…BR-003, UR-001…UR-005, FR-001…FR-005, NFR-001…NFR-006, редакция @v1.
- Уточнены идентификаторы заметок: полный UUID4 вместо короткого усечения, чтобы уменьшить риск коллизии.
- Конкретизированы границы гарантии атомарности и индивидуальной проверки удобства.

## Процесс изменения

1. Создать ветку с REQ-ID и Issue с причиной изменения и влиянием на связанные требования.
2. Изменить текст требования и увеличить его @vN ровно на 1; обновить registry.json.
3. Обновить критерии, связанные тесты и этот changelog.
4. Открыть PR. check_requirement_versions.py сравнивает определения с базой PR; изменение без увеличения версии блокирует CI.
5. После проверок объединить PR; RTM обновляется автоматически. ID не переиспользуются, удаление оформляется статусом retired.
