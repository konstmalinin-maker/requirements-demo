# Software Requirements Specification (SRS)

**Проект:** Менеджер заметок. **Версия SRS:** 1.1. **Дата:** 16.11.2026.
**Автор:** Малинин Константин Николаевич, М-25 ИО.

## Назначение и границы

Локальный консольный менеджер заметок без сети и сервера. Владелец — текущий пользователь ОС; отдельная регистрация и многопользовательская серверная авторизация в этот выпуск не входят. Данные хранятся в JSON. CLI на русском. Python 3.12+; атомарность и права 0600 проверяются на Linux/POSIX. Одновременная запись несколькими процессами не поддерживается.

## Пользователи и интерфейс

Пользователь создаёт, просматривает, ищет, редактирует и удаляет заметки. Встроенная справка: `note --help`. Конкретный файл выбирается через `--storage PATH` или `NOTES_FILE`; по умолчанию `~/.notes.json`. Для учебной демонстрации используется изолированный файл в каталоге проекта.

## Проверка и ограничения

BR-002 проверяется индивидуальным сценарием исполнителя и тестом справки, а не независимым исследованием новых пользователей. Тест NFR-001 измеряет реальную команду list с 10000 заметок; результаты относятся к указанной среде. Покрытие строк и наличие связей не доказывают отсутствие всех ошибок и не заменяют анализ требований.

## Нормативные ориентиры

IEEE 830-1998 и ISO/IEC/IEEE 29148:2018 используются как ориентиры структуры; формальная сертификация соответствия не заявляется.
